# Ryanlen AI Groupware

빌드 없이 동작하는 정적 HTML 그룹웨어입니다. `index.html`을 브라우저로 열면 됩니다.

- `index.html` / `script.js` — 홈 대시보드 (KPI, 지출 차트, 주요 업무, 이슈 브리핑, 일정, 업무 요청, 할 일, 팀 메시지)
- `shell.js` — 공통 레이아웃 (좌측 내비게이션, 상단바, ⌘K 통합 검색, 알림)
- `styles.css` — 디자인 시스템 (색상 토큰, 레이아웃, 공통 컴포넌트)
- `cost/cost.html` — 비용관리 (초기 자금·지출·런웨이·증빙·고정비)
- `sales/sales.html` — 프로젝트 관리 (수주 등록·진행상태·납품·완료, 일괄 상태 변경)
- `receipt/receipt.html` — 전표 관리 (매출·매입·일반 전표 등록, 승인·반려)
- `ui-kit.js` — 목록형 화면 공통 도구 (토스트, 모달, 페이지네이션, CSV)
- `admin/admin.html` — 관리자 페이지 (회원·등급·메뉴 권한·데이터 관리, 마스터·관리자만 접근)
- `members.js` — 회원 등급(마스터/관리자/일반)·메뉴 권한 공통 모듈
- `agent.css` — 비용관리·관리자 화면 전용 스타일
- `fonts/` — Pretendard 폰트 (외부 네트워크 없이 동작)

단독으로(파일로 직접) 열면 데이터는 브라우저 localStorage(`ai-groupware-*` 키)에만 저장됩니다. 공유 서버로 실행하면 서버 DB에 저장되며, 전체 백업은 관리자 페이지(마스터)에서 내려받을 수 있습니다.

## 여러 기기에서 함께 쓰기 (공유 서버)

`server.py`로 실행하면 데이터가 서버의 `data/groupware.db`(SQLite)에 저장되고, 접속한 모든 기기가 같은 데이터를 봅니다(`sync.js`가 localStorage와 서버를 동기화). 현재 로그인한 회원만 기기마다 따로 기억합니다.

- 실행: `python3 server.py` (기본 포트 8765, `GW_PORT`로 변경)
- 로그인: 처음 접속하면 `login.html`에서 마스터 계정(아이디·비밀번호)을 만듭니다. `data/password` 파일(또는 `GW_PASSWORD`)이 있으면 그 값이 최초 설정 키가 됩니다(없으면 먼저 접속한 사람이 설정하므로 주의).
- 가입: 로그인 화면의 **가입 요청**에서 이름·희망 아이디·전화번호·이메일을 보내면 관리자 페이지 → **가입 요청** 탭에 쌓입니다. 마스터·관리자가 승인하면(희망 아이디가 기본값이며 바꿀 수 있음) 일반 회원으로 등록되고 **초기 비밀번호 `1234`**로 계정이 만들어집니다. 본인이 그 아이디와 1234로 로그인하면 **비밀번호 설정** 화면이 뜨고, 새 비밀번호(8자 이상)를 정해야 로그인됩니다. 관리자가 아이디를 바꿨다면 본인에게 알려 주세요.
- 비밀번호: 본인이 정한 비밀번호는 scrypt 해시로만 저장되어 관리자도 볼 수 없습니다. 잊어버린 직원은 로그인 화면의 **비밀번호 초기화 요청**에서 이름·아이디를 입력해 요청하고(둘이 일치할 때만 접수되며 화면에는 일치 여부를 알려 주지 않습니다), 마스터·관리자가 관리자 페이지 → **요청** 탭에서 **비밀번호 초기화**를 누르면 초기 비밀번호 `1234`로 바뀝니다(마스터는 모든 회원, 관리자는 일반 회원, 본인 요청은 다른 마스터가 처리). 본인은 안내받은 초기 비밀번호로 로그인해 새 비밀번호를 설정합니다. 초기 비밀번호 상태에서는 로그인되지 않고 비밀번호 설정 화면으로만 넘어갑니다. 로그인은 30일 유지되는 세션 쿠키를 쓰고, 5분 안에 5번 틀리면 잠시 막습니다(맞게 입력하면 초기화). 가입 요청은 같은 IP에서 1시간에 5건, 초기화 요청은 10건까지입니다. 승인·초기화 후 본인이 비밀번호를 설정하기 전까지는 1234를 아는 사람이 먼저 설정할 수 있으니 바로 본인에게 알려 주세요.
- 계정 관리: 마스터는 모든 회원, 관리자는 일반 회원의 계정(아이디)을 관리자 페이지 → 회원 관리 → 로그인 계정에서 만들거나 바꿉니다. 왼쪽 위 이름(또는 오른쪽 위 아바타)을 누르면 **내 정보 · 비밀번호 변경 · 로그아웃** 메뉴가 열립니다. 이름·아이디·직급은 관리자만 바꿀 수 있고, 연락처(전화·이메일·주소·비상 연락처)는 본인만 내 정보 또는 회원정보 화면에서 수정합니다.
- 비밀번호를 잊었을 때: 마스터·관리자가 해당 회원의 비밀번호를 초기화하면 본인이 다시 만듭니다. 마스터 본인이 잊었다면 서버에서 `sqlite3 data/groupware.db "DELETE FROM users"` 후 다시 최초 설정을 하세요.
- 자동 실행: `deploy/ai-groupware.service`를 `/etc/systemd/system/`에 복사 후 `sudo systemctl enable --now ai-groupware`
- 백업: 하루 첫 저장 때 `data/backups/groupware-날짜.db`에 전날 상태가 보관됩니다(최근 90일은 매일, 그 이전은 달마다 하나씩 영구 보관).
- 예전 `data/store.json`이 있으면 DB가 비어 있을 때 처음 한 번 자동으로 옮겨 담습니다(원본은 그대로 남습니다).
- 같은 데이터를 두 사람이 동시에 고치면 나중에 저장한 쪽에 안내가 뜨고 최신 내용으로 다시 불러옵니다.

권한 등급은 **마스터 > 관리자 > 일반** 3단계입니다.

- **마스터**: 모든 메뉴 접근, 등급 지정, 메뉴별 접근 권한 설정, 백업 복원·전체 초기화
- **관리자**: 관리자 페이지 접근, 일반 회원 추가·수정·비활성화·삭제, 백업
- **일반**: 메뉴 권한에서 허용된 메뉴만 사용

관리자 페이지는 마스터·관리자만 접근할 수 있습니다(고정). 마스터는 최소 1명 유지되며 항상 모든 메뉴에 접근합니다.
공유 서버로 실행하면 로그인한 회원 기준으로 등급이 적용됩니다. 다만 데이터 저장 API는 로그인 여부만 확인하고 등급별 쓰기 제한은 화면(브라우저)에서만 적용되므로, 신뢰하는 팀 안에서 쓰는 용도입니다.
