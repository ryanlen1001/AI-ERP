      가입 요청

      로그인 화면에서 들어온 가입 요청입니다. 승인하면 일반 회원으로 등록되고 초기 비밀번호 1234로 계정이 만들어집니다. 본인이 첫 로그인 때 새 비밀번호를 설정하며, 설정한 비밀번호는 관리자도 볼 수 없습니다. 요청자가 입력한 희망 아이디가 기본으로 채워지며, 바꾸면 그 아이디를 본인에게 알려 주세요.

      비밀번호 초기화 요청

      로그인 화면에서 이름과 아이디가 일치해 접수된 요청입니다. 비밀번호 초기화를 누르면 비밀번호가 초기 비밀번호 1234로 바뀌고, 본인이 다음 로그인 때 새 비밀번호를 설정합니다. 처리한 뒤 본인에게 알려 주세요.
